# The Sequence

The brick-by-brick sequence, read left to right like a video timeline.

Left to right is time. The first interaction starts at the left edge. Everything happening at the same moment stacks vertically in the same column. The sequence app reads the timeline left to right, like scrubbing through a video.

## Column 1 — Bootstrap English manifest

The first interaction. The trigger. The law every brick below it obeys. Plain words, short sentences, one idea per line. If a three-year-old can say it back, it is Bootstrap English.

## Column 2 — Python and Node.js (stacked)

The dual runtime. Python and Node.js run at the same time, stacked in the same column, not side by side. Each brick has a Python twin and a Node.js twin. The twins compute the same thing; the receipt proves they agree.

- `python-brick.py` — the Python twin
- `node-brick.js` — the Node.js twin

## Column 3 — Rust + Tari

The foundation. Rust with Tari underneath. The base the dual runtime stands on. Immutable, verifiable, the ground the wall is built on.

## Column 4 — Motion layer

The presentation surface. Motion 3.5, GSAP, WebGPU. How the wall is shown, not how it is built.

## The rule

Every column answers to the column before it. The Bootstrap English manifest governs. The dual runtime executes. Rust-Tari anchors. The motion layer presents. The sequence app organizes the rungs in order.
