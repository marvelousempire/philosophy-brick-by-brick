# Brick by Brick — Bootstrap English Manifest

A brick is a guaranteed known: a unit of verified work with a demonstrable receipt. All variables solved means the claim, the computation, and the receipt agree, confirmed by an independent checker that sits OUTSIDE the brick.

Pipeline: Bootstrap English manifest -> Makefile -> Bash (to the limit) -> Python. The receipt check is not part of the brick; it is part of the wall.

Zero trust: no brick is trusted because it was laid. Each one is inspected. A brick can compute correctly and still lie about what it computed — which is exactly why the audit lives outside it.
